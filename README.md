# Descrição do projeto:
Um editor de slides simples, feito inteiramente com HTML, CSS e JS (e algumas API's feitas em JS). O visual do projeto inspira-se nos editores da Google (Google slides). E o projeto tem como principal objetivo ser um editor de slides completo, para uso real de um usuário.

## Tecnologias:
### API Moveable:
[CDN]: (https://daybrush.com/moveable/release/latest/dist/moveable.min.js)
A API Moveable foi utilizada para permitir: arrastar, redimensionar e rotacionar os elementos dos slides, como as caixas de texto e imagens.

### API Rangy:
[CDN]: (ttps://cdn.jsdelivr.net/npm/rangy@1.3.2/lib/rangy-core.min.js)
[CDN]: (https://cdn.jsdelivr.net/npm/rangy@1.3.2/lib/rangy-classapplier.min.js)
A API Rangy foi utilizada para permitir estilizar os elementos dos slides, dentre as suas funções estão: alterar a cor dos textos, adicionar: negrito, itálico, sublinhado, tachado (ou riscado) e sobrelinha, adicionar marcações sobre palavras selecionadas, alterar a fonte das palavras e aumentar o tamanho da fonte.
